# This is the beggining of a simple build of a Dashboard with a raspberry pi pico w and an LCD screen (16x2)

## The premise
* The pico is connected with two buttons and a screen - these buttons (b1 and b2) cycle through request options and request, respectively; 
* The screen displays the selected output; 
* The goal is to guarantee that once plugged in, the pico wont require further set up other than thapi modifications; 
* This early version has only access to two pages, but it can be set up however you wish; 

[note: this is a very early one day build and requires further improvements]
